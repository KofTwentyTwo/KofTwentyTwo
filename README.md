## Foundations for building and shipping

- **[AppKit](https://github.com/KofTwentyTwo/AppKit)** — Shared .NET foundations
  for Windows applications: settings, logging, identity, secrets, application UI,
  and Velopack updates, with WinUI 3 and WPF adapters.
- **[Windows app template](https://github.com/KofTwentyTwo/windows-app-template)** —
  Start a WinUI 3 application with AppKit, an optional CLI, stable/dev release
  channels, and repository quality gates.
- **[Standards](https://github.com/KofTwentyTwo/standards)** — Public development
  and security policies, coding conventions, repository checks, and reusable
  workflows, including Windows release signing.
- **[Munitor](https://github.com/KofTwentyTwo/Munitor)** — A CircleCI orb for
  building, testing, packaging, and deploying projects from a shared configuration.

## At QRun-IO

**[QQQ](https://github.com/QRun-IO/qqq)** is a metadata-driven Java application
framework. Define data models and business rules, then build APIs, processes,
and administration interfaces around the same application metadata.
Learn more at [qrun.io](https://qrun.io).

The ecosystem includes [qctl](https://github.com/QRun-IO/qctl), the
[React dashboard](https://github.com/QRun-IO/qqq-frontend-material-dashboard),
[MCP middleware](https://github.com/QRun-IO/qbit-middleware-mcp), and
[QBits](https://github.com/orgs/QRun-IO/repositories) for application features
and integrations.
