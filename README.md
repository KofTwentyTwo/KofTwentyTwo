# James Maes

CTO at Greater Goods and [Me.Health](https://www.me.health).
Founder of [QRun-IO](https://qrun.io). Software engineer at heart.

My work spans product direction, architecture, and engineering leadership.
A recurring interest is making complex systems easier to build, understand,
and maintain. The projects here include application frameworks, shared tooling,
desktop apps, and ongoing experiments.

## Projects and tools

- **[QQQ](https://github.com/QRun-IO/qqq)** — A metadata-driven Java application
  framework for building business applications.
- **[Standards](https://github.com/KofTwentyTwo/standards)** — Shared coding,
  development, and security practices, with repository checks and reusable workflows.
- **[Munitor](https://github.com/KofTwentyTwo/Munitor)** — A CircleCI orb for
  building, testing, packaging, and deploying applications.
- **[AppKit](https://github.com/KofTwentyTwo/AppKit)** — Shared .NET foundations
  for Windows apps, with WinUI 3 and WPF adapters.
- **[gclo](https://github.com/KofTwentyTwo/gclo)** — Clone and update an
  organization's GitHub repositories in parallel.
- **[MarkdownViewr](https://github.com/KofTwentyTwo/MarkdownViewr.Windows)** —
  A Windows Markdown reader with live reload, themes, highlighted source,
  printing, and PDF export.
